# 100 Days of Code — UPES (Days 1–96)

The original files from the supplied ZIP have been kept unchanged.

Additional solutions are provided as `Q###.c` files in this folder. They cover the missing question numbers identified from the supplied repository and the Day 1–96 question screenshots.

Compile a file with:
`gcc Q113.c -o solution`

For programs that read or write files, use the filenames described in the question (for example `input.txt`, `info.txt`, or `numbers.txt`) in the same working directory.

Note: file-handling programs expect their sample input files to be present. A few questions have input/output formats that are not fully specified in the screenshots; these solutions use simple, standard console input conventions.
